============================================================
FUSION 2026 AUDIO TRACK DIRECTORY
============================================================

To use your custom audio/song:
1. Copy or rename your audio file to:
   fusion-song.mp3
2. Place it in this exact folder:
   /public/audio/fusion-song.mp3

Supported formats:
- .mp3 (default: fusion-song.mp3)
- .wav / .m4a / .ogg (if you use a different filename or extension,
  simply update the `AUDIO_FILE_PATH` in `src/config/eventData.js`).

Note: If no audio file is provided, the website automatically falls
back to an ambient synthesizer so playback never fails or crashes!
